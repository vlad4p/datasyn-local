Metodología y límites

Pipeline: landing CSV → bronze → silver → clasificación LLM → gold → este dashboard (datos embebidos).

  • FB: ~67k comentarios clasificados; autores casi anónimos.
  • TW: muestra de replies a tweets con alto volumen (~3.5k).
  • Posición LLM: apoyo_izquierda, derecha_o_troll, neutral, ambiguo, inclasificable.
  • Narrativa: heurística SQL sobre resumen — no topic modeling.
  • Ráfaga: ≥3 trolls mismo autor/día/cuenta.
  • Entidades: inferencia por display name; vínculos débiles por homonimia.
  • Copy-pasta: clusters texto ≥5 repeticiones; resumen LLM ≥10.
