Metodología y límites

Pipeline: seed curado (config/identidades*.csv) → silver.identidad / identidad_cuenta → gold.v_monitor_* (FB legacy + twikit) → este dashboard.

  • v1 usa datos vivos de Facebook legacy y Twitter/X (twikit). Instagram/TikTok quedan listos en el modelo de identidad pero sin filas aún.
  • Clasificación LLM + heurísticas de narrativa — no es verdad absoluta.
  • Bots: heurística (cuenta nueva, ratio follow alto, bio vacía, alto output / baja audiencia). No prueba de automatización.
  • co_rafaga / co_followers = sincronía o audiencia compartida, no prueba de coordinación.
  • Muestra TW parcial (tweets seleccionados + replies). FB tiene más volumen clasificado.
  • Campos OSINT (Wikidata, sitio, provincia) se completan en el seed curado — checklist en la doc técnica.
